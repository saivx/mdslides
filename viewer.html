    MD Slides – Help

    Getting started

    1. In chrome://extensions open this extension’s Details and turn on Allow access to file URLs (required for local files).
    2. Open any local .md file in Chrome (file:///...) and it opens here automatically. Or click Open… and paste a path.
    3. The file is re-read every second, so changes you save in your editor appear on screen without a refresh.

    Pages

    • Each H1 is one page (Settings: also split on H2). Tall pages scroll. The zoom controls work like Chrome’s PDF viewer: − 100% + zoom, click the percentage to reset, and the three icons beside it choose the page mode (the active one is highlighted): default size (same font size on every page, for consistent reading), fit to width (fills the screen width, good for projectors) and fit to height (shrinks a long page to one screen).
    • All pages shows the whole document as one scroll. The page box (e.g. 3 / 10) accepts a number to jump.
    • The ☰ sidebar lists the .md files in the file’s folder and sub-folders.

    Content

    • GitHub-style rendering, syntax-coloured code, task lists, tables.
    • Images and links relative to the file work (![](img/a.png), [x](other.md)); links to other .md files open in the viewer.
    • Tables: click a column header to sort (again to reverse, a third time to reset); the header row stays visible while scrolling. Columns wrap to fit the page. On a table that is too wide for the page, faint icons appear at its top right: switch between wrap and scroll sideways (first column frozen), or open the table full screen. Settings → Tables sets the default.
    • Code blocks: hover and click Copy.

    Export

    • Export HTML – one self-contained file (CSS and images embedded) that works anywhere.
    • Export PDF – opens Chrome’s print dialog; choose Save as PDF. Every page starts on a new sheet. Header, footer, page numbers and a “Confidential” watermark come from Settings → PDF. In the print dialog, untick “Headers and footers” (Chrome’s own) and tick Background graphics. Page numbers like “Page 2 of 9” need Chrome 131 or later.

    Notes

    • Reload the extension on chrome://extensions after changing its files.
    • Drag-and-dropped files are shown as a static copy (no live reload, no relative images).
